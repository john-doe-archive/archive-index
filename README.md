# Archive Index

This repository maintains a structured index of archived digital records.

## Purpose

- Record archive identifiers and filenames.
- Track revisions to historical indexes.
- Preserve references to records transferred between collections.

## Repository Notes

Some records were imported from an earlier index. Not all original metadata was preserved during the transfer.

Revision history may contain information that is absent from the current files.
